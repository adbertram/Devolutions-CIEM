# Privileged account management

**Source URL:** https://docs.devolutions.net/pam/rdm/privileged-account-management/

---

Devolutions PAM accounts can be discovered, imported, and configured directly within Remote Desktop Manager. This allows PAM users to manage providers and propagation scripts, as well as discover and import accounts without needing to navigate to Devolutions Server's or Devolutions Hub's web interface.
