# Tasks

**Source URL:** https://docs.devolutions.net/pam/hub/privileged-access-reports/tasks/

The
Tasks
report allows you to monitor the status of password resets in specific PAM vaults. It essentially follows the password resetting flow by giving you the actions that the Devolutions Hub Services performed.

Each entry in the task list corresponds to a separate password reset action. You can filter them by
Entry name
or
Provider
to search for password resets done on specific entries.
The
Status
column shows the status of the password reset, which can either be
Created
,
Pending
,
In Progress
,
Completed
,
Canceled
, or
Failed
. As with the entry name and provider, you can filter the status column to see only tasks with certain statuses.
Hover over the icon in the status cell to see the complete history of that task's status.
