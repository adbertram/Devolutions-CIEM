# SSH local account discovery configuration

**Source URL:** https://docs.devolutions.net/pam/server/scan-configurations/ssh-account-discovery/

---

The SSH local accounts account discovery configuration allows Devolutions Server to scan the host to find accounts. The accounts will not be automatically added in the Privileged Access Management folders.
