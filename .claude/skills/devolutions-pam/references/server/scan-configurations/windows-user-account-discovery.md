# Windows account discovery configuration

**Source URL:** https://docs.devolutions.net/pam/server/scan-configurations/windows-user-account-discovery/

---

The
Windows
account discovery configuration allows Devolutions Server to scan the host to find accounts. The accounts will not be automatically added in the Privileged Access Management folders.
