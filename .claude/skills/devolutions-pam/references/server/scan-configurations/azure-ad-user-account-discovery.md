# Entra ID account discovery configuration

**Source URL:** https://docs.devolutions.net/pam/server/scan-configurations/azure-ad-user-account-discovery/

---

The
Entra ID User
account discovery configuration allows Devolutions Server to scan the Entra ID to find accounts or groups. They will not be automatically added in the Privileged Access Management folders.
Add new Entra ID account discovery configuration
General
Option
Description
Name
Display name of the Entra ID account discovery configuration.
Configuration
Option
Description
Provider
Name of the Entra ID provider.
Search mode
The Search can be set by Groups or Roles.
Groups: Retrieves the Entra ID accounts that are members of the selected groups.
Roles: Retrieves the Entra ID accounts to which the selected roles have been assigned
Schedule
Option
Description
Recurrence
If enabled, will run the scan on a regular basis depending on the schedule configuration.
Start
Starting date and hour of the scan recurrence.
Every
Number of units.
Unit
Units of time.
Action
Option
Description
Start scan on save
If enabled, will start the scan upon saving the modifications.
