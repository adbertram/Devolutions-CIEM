# Domain account discovery configuration

**Source URL:** https://docs.devolutions.net/pam/server/scan-configurations/domain-account-discovery/

---

The Domain account discovery configuration allows Devolutions Server to scan a domain area to find accounts. The accounts will not be automatically added in the Privileged Access Management folders.
