# SQL account discovery configuration

**Source URL:** https://docs.devolutions.net/pam/server/scan-configurations/sql-account-discovery/

---

The SQL account discovery configuration allows Devolutions Server to scan the host to find accounts. The accounts will not be automatically added in the Privileged Access Management folders.
Add new SQL account discovery configuration
