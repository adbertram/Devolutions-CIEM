Start by entering a
Name

Description

Private
: A private PAM vault is not visible to users that do not have access to it. Thus, vault access requests cannot be performed. You can only access it by invitation.
Public
: A public vault is visible to all users of the data source, even to those who do not have access to it. A user can request access to the public vault.
