# Unmanaged (password reset only) providers

**Source URL:** https://docs.devolutions.net/pam/server/providers/password-reset-only-providers/

---

Within Devolutions PAM, a provider typically performs the entire password management lifecycle, including discovery, heartbeat, and password rotation. However, it is not always appropriate, necessary, or feasible to maintain the entire lifecycle for an identity provider. In such cases, unmanaged providers, also known as
Password reset only
providers, are utilized.
Unmanaged providers execute only a single phase of the password management lifecycle: the password rotation phase.
