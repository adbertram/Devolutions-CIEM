# External PAM integrations

**Source URL:** https://docs.devolutions.net/rdm/concepts/advanced-concepts/external-pam-integrations/

---

Remote Desktop Manager can combine with external privileged access management integrations to secure
and control privileged access. RDM injects PAM credentials directly into remote sessions so credentials
do not need to be stored in RDM while rotation, approval, and auditing stay centralized in the PAM
system.

Related partner integrations include CyberArk, BeyondTrust Password Safe, and Delinea Secret Server.
