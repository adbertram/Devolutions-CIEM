# Required package for each PAM action

**Source URL:** https://docs.devolutions.net/pam/kb/knowledge-base/required-package-pam-actions/

---

PAM actions depend on the Devolutions package assigned to the user. Each package includes the previous
one.

- Workforce password management: access to Server and Hub web interfaces, limited to assigned shared
  vaults and PAM vaults. Manual password reset and heartbeat checks are unavailable in PAM vaults, and
  users cannot launch sessions or manage PAM.
- Remote access management: access to Devolutions Launcher for sessions configured with PAM accounts
  through Devolutions Gateway.
- Remote desktop management and IT operations: access to Remote Desktop Manager and Devolutions
  Launcher to launch sessions configured with PAM accounts. Manual password reset and heartbeat checks
  remain unavailable in PAM vaults, and users cannot manage PAM.
- Privileged access management: access to Remote Desktop Manager, Devolutions Launcher, PAM
  management, and all PAM functionality.
